minios v1.1.0: UEFI, local APIC and I/O APIC, screen console, audit fixes

Everything merged after v1.0.0 (parts 2 to 4), plus the release commits.
docs/PLAN.md section 11 records the main additions and fixes.
- A UEFI loader beside the BIOS one, with the same boot_info hand-off. The
  in-kernel test suite and the init demo also run under OVMF in make test;
  the other test configurations run under SeaBIOS only.
- The local APIC timer and the I/O APIC, found through ACPI and calibrated
  against the HPET, with PIT channel 2 as the fallback reference. The 8259
  and PIT path stays, forced by the noapic option and chosen automatically
  when the APICs are unusable. The x2apic option runs the kernel in x2APIC
  mode; make test-x2apic, separate from make test, runs the in-kernel
  suite (debug build) that way and needs QEMU 9.
- A screen console, UEFI GOP framebuffer or BIOS VGA text, fed from a
  16 KiB log ring that replays the boot.
- kmalloc redzones in debug builds, gdb helpers, runner self-tests,
  per-method A20 test builds, and make check.
- Fixes from an audit of the code and from adversarial reviews of the
  screen console and of the audit fixes. Every v1.0.0 defect listed in its
  tag is fixed (the banner by this release's version bump). Most fixes
  have a test that fails without them; some hardware fallbacks cannot be
  reached under QEMU, and README.md's known limitations name the main
  ones.

Changes for anyone coming from v1.0.0:
- boot_info is now version 4, and the kernel refuses any other version, so
  the loader and the kernel must come from the same release.
- At most 256 tasks, counting kernel threads, zombies and the boot and
  idle tasks; spawn then fails with -EAGAIN.
- sleep_ms(ms) waits for ms ticks plus one, one tick more than before, so
  it no longer returns early within the current tick. wait() returns
  -EFAULT without reaping a child when the status pointer is unmapped or
  read-only. An x87 error a program has unmasked raises #MF and kills the
  process.
- RAM above the 512 GiB direct map is ignored, with a warning.
- New boot options: console=serial, nohpet, x2apic and noapic.
- make now also needs mtools; make test also needs ovmf and gdb; make
  check needs clang-format and clang-tidy.
- The boot banner reads "minios 1.1.0".

Booted only under QEMU's TCG emulator (8.2, and 9.2 for x2APIC), with
SeaBIOS and OVMF; the host unit tests run natively. Never booted on real
hardware.
