minios v1.0.0: milestones M0-M8 of docs/PLAN.md

Tagged later, when v1.1.0 was released. This is v1.0 as docs/PLAN.md
defines it (goals in section 1, definition of done in section 10): a
two-stage BIOS loader, 4-level page tables with W^X, an IDT entry and a
decoded handler for every exception vector (a fault in ring 3 kills the
process, an unexpected one in the kernel panics), the 8259 PIC and PIT, a
preemptive round-robin scheduler, and ring-3 processes in their own
address spaces with 8 syscalls (the plan had 7; section 11 records why).
make test boots the kernel under QEMU in CI.

Known defects at this commit include these, all fixed in v1.1.0 (most in
d40a0e8):
- A ring-3 process could set RFLAGS.NT, which survived SYSCALL and made
  another task's iretq fault: it could kill other processes or panic the
  kernel. README.md's claims that processes are isolated from each other
  and that faults kill only the faulting process do not hold here.
- Trap entry left a user-set RFLAGS.AC in place, which switched SMAP off
  in handlers. Nothing limited the number of tasks, so a spawn loop could
  take every free page. vmalloc never reused address space, so task churn
  leaked page tables, and a zombie kept its memory until it was reaped.
- #MF and #MC were never enabled (CR0.NE and CR4.MCE stay clear). An NMI
  that arrived while the console lock was held panicked the kernel.
- Stage 2 dropped E820 entries whose ACPI "enabled" bit was clear, which
  some BIOSes leave clear on every entry: such a PC would see no RAM. TSC
  calibration waited for PIT ticks with no deadline, so a PIT that never
  ticked hung the boot silently.
- None of the three A20 methods ever ran under test, since SeaBIOS starts
  with A20 on (12ca23e added a test build per method; none was broken).
- pit_is_programmed_for_the_tick_rate depends on host speed and failed CI
  on this exact tree (fixed in 1e7d820), so make test can fail spuriously.
- The boot banner reads "minios 0.1.0": the version string was not raised.

Booted only under QEMU 8.2's TCG emulator with SeaBIOS (the host unit
tests run natively); never booted on real hardware. Use v1.1.0.
